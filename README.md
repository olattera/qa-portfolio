QA Portfolio: DemoQA Manual Testing

Project Overview

This project demonstrates manual web application testing using the public DemoQA website.

The project covers test planning, test case design, checklists, defect documentation and test execution reporting.

Application Under Test

DemoQA
https://demoqa.com

DemoQA is a public practice website created for learning and demonstrating web automation and software testing techniques.

Testing Scope

The following modules are covered:

* Elements
    * Text Box
    * Check Box
    * Radio Button
    * Web Tables
* Forms
    * Practice Form
* Alerts, Frames & Windows
    * Alerts
    * Browser Windows

Testing Objectives

The main objectives are:

* verify core functionality of selected modules;
* check positive and negative scenarios;
* validate required fields and user input;
* verify UI behavior;
* check data creation, editing and deletion;
* identify defects and usability issues;
* demonstrate structured manual QA documentation.

Testing Types
