6. Conclusion

The DemoQA project demonstrates the structure of a manual QA testing cycle:

1. Define the testing scope.
2. Prepare test documentation.
3. Design positive and negative test cases.
4. Use a checklist for quick coverage.
5. Document potential defects.
6. Summarize test execution results.

The project can later be extended with API testing, SQL validation and UI automation.
